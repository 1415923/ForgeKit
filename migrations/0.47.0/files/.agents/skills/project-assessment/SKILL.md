# Project Assessment

Assessment is read-only. Determine the requested result, then load exactly one branch:
- Adoption fit or governance intensity: [adoption](references/adoption.md).
- Existing-project takeover or current-state audit: [takeover](references/takeover.md).

Inspect available evidence before asking for missing facts. Report evidence, uncertainty and the smallest useful next step.
The branches do not invoke each other, initialize the project or repair findings. An explicit recording request permits only that bounded write.
The shared project entry contract applies; do not repeat authorization already provided for the requested action.
