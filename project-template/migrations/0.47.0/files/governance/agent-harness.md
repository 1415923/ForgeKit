# 上下文与搜索

读者：维护项目入口和上下文策略的人员。仅在调整搜索、加载或恢复机制时读取。不要在这里记录业务事实。

首次确认项目边界。用户已给出具体路径或目标时，直接搜索相关实现及调用边界；广义接手、定位不明时使用 codebase-map。不要每次编辑重读地图或全部文档。

只加载命中的 Skill 分支、技术栈和事实 owner。缺少信息先用只读搜索查证；只有会改变结果、授权目标或验收的问题才需要用户决策。跨模块、文件数量和可修复的局部失败不自动阻塞。

按已授权范围完成实现、验证和必要修复。真实高影响合同按 ai-engineering-loop 执行；已批准阶段内不重复索取授权。缺少某项验证时报告限制并继续独立工作，不声称该验证通过。

关键结论按 work-session-checkpoint 保存到对应 owner；恢复时读取入口和相关当前状态，不重新全量加载治理文档。规则升级后启动新会话。
